Python · C++ · P2P

SHACK360 — S360 Framework

SHACK360 is a modular framework for S360chain: a peer-to-peer, file-backed chain with Python orchestration and optional C++ hashing modules. It provides tools for storing immutable S360 files, light consensus, and plug-in subsystems for hashing, networking and security. The documentation in the repo is the canonical setup and install guide for framework components and deployment.

  • → Modular installs: pip packages, C++ hasher plugin, and optional node components
  • → File-backed chain storage, simple PoW-style hashing, and P2P syncing
  • → Docs-first setup: follow the repository's README and DESIGN_DOCUMENT for deployment
Docs Code Python C++
Quick start & install 
git clone https://github.com/awaaladin/SHACK360_pkg.git
cd SHACK360_pkg
python -m venv venv
# Windows PowerShell
.\venv\Scripts\Activate.ps1
# macOS / Linux
source venv/bin/activate
pip install -r requirements.txt

# Optional: build the C++ hasher (if present)
cd hasher || true
mkdir -p build && cd build
cmake .. && cmake --build . --config Release
cd ../..

# Install editable package
pip install -e .

# Run migrations (if the project has Django apps)
python manage.py migrate
python manage.py runserver
Follow the repository's Docs and DESIGN_DOCUMENT.md for configuration, C++ build details, and deployment notes.
